COUCH GAMES / CREATOR PREVIEW

Your first couch game.

This local development kit contains the current Godot addon, a small editable 3D game, Creator Hub and the prebuilt couch diagnostic/package tools. It needs no Rust, Python, Docker or database server on the creator's computer.

1. Connect your editor

Setup detects the supported standard Godot editor using the same runtime policy as the addon. Choose your existing Godot.app, or use Download Godot to open the pinned official download page. Extract the standard editor, move it into Applications, open it normally if macOS requests approval, and select it in setup.

Godot is a separate download. Setup does not install it automatically, replace another editor, or download export templates.

2. Install the kit

Choose the parent installation folder, then select Install GDK. Setup creates a versioned subfolder and verifies every packaged file. It never replaces a different existing installation. Open Couch Games Creator.app inside that folder to return later; you can drag it to your Dock.

3. Make a project

  1. Open Creator Hub and choose New 3D game.
  2. Give the game a name and select a parent folder. A new independent project folder is created.
  3. Choose Open in Godot. Let the editor import its resources.
  4. Press Godot's Run Project button (F6 runs the selected scene; F5 runs the project). The starter supports controllers or a keyboard.

Xbox A / PlayStation Cross joins and jumps; left stick or D-pad moves. Hold B / Circle to leave. Keyboard: Enter joins, WASD/arrows move, Space jumps, Backspace leaves. F11 toggles fullscreen. Pair controllers with the computer.

4. Change something

The starter is based on Little World. Open examples/little_world/world.gd to change the world and player colors. Open character.gd to change movement and jumping. The addon lives under addons/couchgames/; its version is copied into each project rather than silently shared with every game.

Platform.input.player_joined.connect(spawn_character)
Platform.input.player_left.connect(remove_character)

var move = Platform.input.movement(player_id)
var jump = Platform.input.consume_jump(player_id)

Implement the spawn/remove callbacks in your game. IDs are session-local player slots, 1–16. Disconnect releases the slot; reconnect requires another join. Sixteen software slots do not guarantee sixteen simultaneous wireless connections on every computer. Motion and specialty controllers remain experimental.

5. Play and diagnose

After the first editor import, Creator Hub's Play button opens the source game as a separate process. Close its window when finished. This preview does not provide packaged-game supervision or private publishing.

From a terminal in the installed kit folder:

./bin/couch doctor --require-godot
./bin/couch --godot /path/to/Godot.app doctor --require-godot

validate, install and library operate on provisional release manifests and local content. They do not build or launch a game. The creator init, run, pack and publish commands are not yet implemented.

What comes next

General actions/remapping, reusable lobby/pause scenes, local save APIs, a 2D starter, qualified exported packages and private sharing are still being developed. You can edit and run this 3D project today without those services. This internal preview is ad-hoc signed for local testing, not a notarized public installer; the GDK's release licensing is still being decided.

Files and troubleshooting

Projects live in the folders you choose. Creator Hub keeps its recent list in Godot's user-data directory for CouchGames/CreatorHub. Setup remembers a manually selected Godot path in its macOS preferences. Use Detect automatically to clear that choice. Hub startup logs are in logs/creator-hub.log inside the installed kit. To remove a kit version, quit its apps and remove its versioned folder; projects elsewhere are preserved.
